# Stats 2 Quiz 1 Prep

[![Deploy](https://github.com/arshanalikhan/iitm-stats2-prep/actions/workflows/deploy.yml/badge.svg)](https://github.com/arshanalikhan/iitm-stats2-prep/actions/workflows/deploy.yml)

An unofficial study site for **IIT Madras BS, BSMA1004 Statistics for Data Science II**, Quiz 1 (Weeks 1–4, Sep 2026 term, quiz on 15 Nov 2026).

**Live site: https://arshanalikhan.github.io/iitm-stats2-prep/**

| Page | What it does |
|---|---|
| Week notes | Week 0 recap and Weeks 1–4: joint, marginal and conditional PMFs, independence, functions of random variables, expectation, variance, covariance, Markov and Chebyshev, CDF and PDF |
| Formula sheet | Everything to memorise, and what the quiz paper prints for you |
| Worked examples | 20 quiz-style problems solved step by step, each with its trap |
| Past quiz patterns | Every Quiz 1 since June 2022 tagged by pattern: week-marks chart, heatmap, chance of each pattern, a predicted blueprint |
| Practice | 117 original MCQ, multi-select and numeric questions with explanations |
| Number drills | 21 generators that make fresh problems and show the full working |
| Mock quizzes | 40-mark timed papers: predicted, three fixed, and random |
| Traps, Resources | Exam-morning checklist; every lecture link |

Questions are original: course and past-paper questions were used only as models, with new numbers and settings. Progress is stored only in your browser.

## Repository layout

```
src/
  pages/            page markup, one file per page (00-shell.html is the app frame)
  styles/           stylesheets, numbered in cascade order
  data/
    questions/      practice bank: helpers.js, then week0.js … week4.js
    mocks.js        the three fixed mock papers
    patterns-data.js  past-paper statistics (generated by tools/analysis/qp_stats.py)
  js/
    core.js         helpers, maths typesetting, numeric answers, the shared question card
    drills/         drill generators: helpers.js, then week1.js … week4.js
    practice.js     practice page
    drills-ui.js    drills page
    mock.js         mock quizzes (timer, scoring, results)
    patterns.js     past-quiz-patterns page and the predicted paper
    notes.js        week notes navigation and worked-example toggles
    home.js         home page: progress, plan, countdown, hero animation
    shell.js        theme, phone helpers, routing, boot (loaded last)
tools/
  build_site.py     builds site/ from src/
  analysis/         scripts used for the past-paper analysis (they read local data that is not in this repo)
tests/
  check_data.js     validates the question bank, mocks and pattern data
  check_drills.js   runs every drill generator thousands of times
docs/               architecture, content guide, analysis method
.github/workflows/  build, test and deploy to GitHub Pages
```

## Develop

Requirements: Python 3.10+ and Node 18+. No packages to install.

```bash
python tools/build_site.py
```

```bash
python -m http.server 8767 --directory site
```

Then open http://localhost:8767/.

Run the checks (CI runs the same ones):

```bash
node tests/check_data.js
```

```bash
node tests/check_drills.js
```

## Deploy

Every push to `main` runs the tests, builds `site/` and publishes it to GitHub Pages (see [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)). `site/` is generated and is not committed.
