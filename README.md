## What's inside

| Page | What it gives you |
|---|---|
| **Week notes** | Week 0 recap and Weeks 1–4, one week at a time |
| **Graded assignments** | Answers, short working and a practice twin per question, added only after each deadline |
| **Formula sheet** | What to memorise, and what the quiz paper prints for you |
| **Worked examples** | 20 quiz-style problems, solved step by step |
| **Past quiz patterns** | Every Quiz 1 since 2022, tagged: heatmap, chances, predicted paper |
| **Practice** | 117 original questions with explanations |
| **Number drills** | 21 generators with fresh numbers and full working |
| **Mock quizzes** | 40-mark timed papers: predicted, fixed and random |
| **Traps · Resources** | Quiz-morning checklist and every lecture link |

Questions are original: course and past-paper questions were used only as models, with new numbers and settings. Progress is saved in your browser only.

## Project structure

```text
.
├── src/
│   ├── pages/          HTML, one file per page
│   ├── styles/         CSS, numbered in cascade order
│   ├── data/           questions, mocks, past-paper stats
│   └── js/             app modules and drill generators
├── tools/              build and analysis scripts
├── tests/              data and drill checks
├── docs/               guides
└── .github/workflows/  test, build, deploy
```

### Source code (`src/js/`)

| File | Responsibility |
|---|---|
| `core.js` | Storage and DOM helpers, maths rendering, answer checking, the question card |
| `practice.js` | Practice page: filters, paging, saved answers |
| `drills-ui.js` | Drills page: current problem, streaks |
| `drills/` | Drill generators, one file per week |
| `mock.js` | Mock quizzes: timer, palette, scoring, results |
| `patterns.js` | Past-quiz-patterns page and the predicted paper |
| `ga.js` | Graded-assignments page: deadline status, notes, practice twins |
| `notes.js` | Week notes navigation, worked-example toggles |
| `home.js` | Progress rings, study plan, countdown, hero animation |
| `share.js` | Share buttons (WhatsApp, copy link) and the GitHub star count |
| `shell.js` | Theme, phone layout, routing, start-up (loaded last) |

### Content (`src/data/`, `src/pages/`, `src/styles/`, `src/assets/`)

| Path | Contents |
|---|---|
| `data/questions/` | Practice bank: `helpers.js`, then `week0.js` … `week4.js` |
| `data/mocks.js` | The three fixed mock papers (40 marks each) |
| `data/patterns-data.js` | Past-paper statistics, generated by `tools/analysis/qp_stats.py` |
| `data/ga.js` | Graded-assignment notes and twins, one week at a time after its deadline |
| `pages/` | `00-shell.html` (app frame), then one file per page |
| `styles/` | `01-tokens-and-base.css` … `10-assignments.css` |
| `assets/` | Saranda House logo files and the link-preview image, made by `tools/make_share_images.py` |

## Getting started

Needs Python 3.10+ and Node 18+. Nothing to install.

```bash
# run the checks (CI runs the same ones)
node tests/check_data.js
node tests/check_drills.js

# build src/ into site/
python tools/build_site.py

# preview at http://localhost:8791
python -m http.server 8791 --directory site
```

## Deployment

Every push to `main` runs the checks, builds `site/` and publishes it to GitHub Pages ([workflow](.github/workflows/deploy.yml)). `site/` is generated, so it is not committed.
